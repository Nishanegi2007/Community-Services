# Alice Public School website (React + Vite + EmailJS)

1. `npm install`
2. Copy `.env.example` to `.env` and fill in your EmailJS service ID, template ID and public key.
   In your EmailJS template use these variables: `from_name`, `reply_to`, `message`.
3. `npm run dev` to start, `npm run build` to create the production build (deploy the `dist` folder to Vercel).

Edit text, photos and news in `src/data.js`.
